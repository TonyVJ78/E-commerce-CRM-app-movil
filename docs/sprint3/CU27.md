# CU-27: cupones y promociones segmentadas

Empresa: Tiendas → seleccionar tienda → Cupones y promociones. Puede crear códigos,
definir porcentaje o monto fijo, fechas, compra mínima, usos globales y por cliente,
segmento objetivo y activación. Cliente: Inicio → Mis promociones → copiar código;
Carrito → código de la tienda → Aplicar.

El servidor cotiza usando el carrito autenticado. El móvil no decide quién pertenece
a un segmento, si quedan usos ni cuánto se cobra. Cambiar o recargar el carrito
invalida su cotización. El checkout vuelve a validar vigencia, límites y segmento.
Para tarjeta, el intento y la confirmación deben usar el mismo mapa de cupones.

Requiere la rama API `codex/cu27-cupones-api`, su migración aditiva de marketing y
su despliegue. No basta con modelos o formularios de Django Admin en el main actual.
No se ejecutan pagos reales en las pruebas.
